# Luminous - кратко

Откройте **Luminous → Settings** в Spotify.

- **Presets** - готовые профили.
- **Appearance** - фон, Canvas/artwork, blur, яркость, прозрачность интерфейса и сила адаптивного света.
- **Motion** - Still / Drift / Float, скорость и Reduce motion.
- **Advanced** - диагностика и служебные инструменты.

В `2.2.3` графический pipeline намеренно упрощён до проверенной стабильной схемы: убраны parallax, Orbit, grain/vignette/detail-quality и изменяемый cross-fade, добавленные в предыдущем рефакторе. Это сделано для устранения мерцания интерфейса при смене треков.

- Защищённые длинные NPV-видео используются как фон напрямую через исходный Spotify `<video>`, без бесполезного для DRM `captureStream()`; основной интерфейс остаётся поверх видео, правая панель сохраняет штатные прокрутку и clipping, а освободившийся video-slot сохраняет размер и заполняется текущей обложкой.
