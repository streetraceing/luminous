# Luminous — кратко

Откройте **Luminous → Settings** в Spotify.

- **Presets** — готовые профили.
- **Appearance** — фон, Canvas/artwork, blur, яркость, прозрачность интерфейса и сила адаптивного света.
- **Motion** — Still / Drift / Float, скорость и Reduce motion.
- **Advanced** — диагностика и служебные инструменты.

В `2.2.1` графический pipeline намеренно упрощён до проверенной стабильной схемы: убраны parallax, Orbit, grain/vignette/detail-quality и изменяемый cross-fade, добавленные в предыдущем рефакторе. Это сделано для устранения мерцания интерфейса при смене треков.
