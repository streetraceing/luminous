# Luminous — quick guide

Luminous turns Spotify into a translucent interface and adapts the background lighting to each cover. When Spotify Canvas/video is available and capturable, it can replace static artwork.

Open Spotify profile menu → **Luminous Settings**.

- **Balanced** — recommended default.
- **Cinematic** — richer colour, depth, and motion.
- **Calm** — restrained and mostly static.
- **Performance** — fewer effects and lower GPU work.

The tabs control media, surface opacity/blur, light intensity, vignette, grain, motion, parallax, cross-fade, and effect quality. **Reduce motion** disables custom movement; **Respect system motion** follows the OS accessibility preference.

If Canvas cannot be captured or is DRM-protected, Luminous automatically keeps the cover artwork. **Advanced** can copy a diagnostics report for bug reports.
